Interface de programmation

Une API (de l'anglais application programming interface) est un ensemble normalisé de classes, de méthodes, de fonctions et de constantes servant de façade par laquelle un logiciel offre des services à d'autres logiciels. Elle est généralement exposée par une bibliothèque logicielle ou un service web et accompagnée d'une spécification décrivant comment les programmes consommateurs peuvent exploiter les fonctionnalités du programme fournisseur, indépendamment de son implémentation.

Typologie

On distingue les API locales, liées à l'édition de liens, des API distantes reposant sur des protocoles comme REST, SOAP ou GraphQL, dont les contrats d'interface sont souvent décrits selon la spécification OpenAPI.

API

Une API est un guichet qui permet à deux logiciels de se parler.

Un logiciel pose une question, l'autre lui envoie la réponse.

Un exemple
L'appli météo d'un téléphone n'a pas de satellite. Elle demande la température à l'API d'un service météo. L'API répond : « 18 °C ».
